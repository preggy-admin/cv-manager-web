
User Guide

Getting Started

Creating Your Account

Visit the CV Manager Web application
Click "Sign Up" in the top navigation
Enter your desired username, email, and password
Click "Register"
Logging In

Click "Login" in the top navigation
Enter your username and password
Check "Remember Me" to stay logged in
Click "Login"
Building Your CV

Adding Work Experience

Navigate to "Work Experience" in the sidebar
Click "Add Experience"
Fill in the form:
Company name
Your position title
Start and end dates
Description of responsibilities and achievements
Click "Save"
Adding Education

Navigate to "Education" in the sidebar
Click "Add Education"
Enter institution, degree, and dates
Add a description if desired
Click "Save"
Adding Skills

Navigate to "Skills" in the sidebar
Click "Add Skill"
Enter skill name
Select category (Technical, Soft Skills, etc.)
Set proficiency level (1-5)
Click "Save"
Adding Languages

Navigate to "Languages" in the sidebar
Click "Add Language"
Enter language name
Select proficiency level
Click "Save"
Adding Publications

Navigate to "Publications" in the sidebar
Click "Add Publication"
Select publication type
Enter title, authors, year, and other details
Click "Save"
Adding Badges & Certifications

Navigate to "Badges" in the sidebar
Click "Add Badge"
Enter badge/certification name
Add issuer and date earned
Optionally add a badge image URL
Click "Save"
Generating Your CV

Click "Generate CV" in the sidebar
Choose a template:
Classic: Traditional, formal layout
Modern: Clean, contemporary design
Compact: Space-efficient for experienced candidates
Choose output format:
HTML: View in browser, can be saved as webpage
PDF: Download as PDF document
Click "Generate CV"
Your CV will automatically download
Job Matching

Click "Job Match" in the sidebar
Paste the job description into the text area
Click "Analyze Match"
Review the results:
Overall match percentage
Skills alignment score
Experience match
Improvement suggestions
Keywords to include
Managing Your Profile

Click "Profile" in the sidebar
Update your:
Personal information
Contact details
Professional summary
Social media links
Click "Save Changes"
Tips for Best Results

CV Optimization

Use action verbs in experience descriptions
Quantify achievements when possible
Include relevant keywords for your industry
Keep formatting consistent
ATS-Friendly Tips

Use standard section headings
Avoid tables and columns
Use simple bullet points
Save as PDF or HTML (not image-based)
Job Matching

Use complete job descriptions for best results
Review suggested keywords
Update your CV based on recommendations
Run multiple job matches for different roles
Troubleshooting

Can't log in?

Check your username and password
Try resetting your password
Clear browser cookies
PDF not generating?

Use HTML format as fallback
Check if you have write permissions
Try a different browser
Data not saving?

Check your internet connection
Refresh the page (unsaved data will be lost)
Contact support if issue persists
