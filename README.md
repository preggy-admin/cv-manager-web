# CV Manager Web

A web-based CV management system that allows users to create, manage, and generate professional CVs.

## Features

- User registration and authentication
- Interactive CV builder with forms
- Multiple CV templates (Classic, Modern, Compact)
- ATS-friendly CV generation
- Job description matching and analysis
- Export to PDF, HTML, and Markdown
- Import from LinkedIn and ORCID (coming soon)

## Quick Start

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python run.py`
4. Visit `http://localhost:5000`
